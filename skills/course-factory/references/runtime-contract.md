# 课程交付与校验接口

在组织课程文件、编写课表或连接总控时读取。脚本只验证可计算的结构，不证明内容质量或已获用户确认。

## 文件布局

默认每门课一个目录，目录内各一份文件，文件名分别包含：`培训需求说明书`、`课程大纲`、`课程计划`、`学员课程讲义`、`教员课程指导手册`、`Storyboard`。可有前后缀。多个版本应移到 `_drafts` 等中间目录，避免猜测正式版本。

文件跨目录或同目录多门课时，在项目根目录创建 `course-deliverables.json`：

```json
{
  "courses": [
    {
      "files": [
        "课程甲/培训需求说明书.md",
        "课程甲/课程大纲.md",
        "课程甲/详细课程计划.md",
        "课程甲/学员课程讲义.md",
        "课程甲/教员课程指导手册.md",
        "课程甲/教员课程PPT-Storyboard.md"
      ]
    }
  ]
}
```

每组必须六份独立 Markdown，课程间不能共用同一文件。只允许项目内真实路径，不能指向排除目录或遗漏其他正式教学文件。排除目录：kb、blind、sources、derived、build、node_modules，以及以 `.` 或 `_` 开头的路径。

## 大纲交接

生成器按以下固定小节和列顺序读取组件清单；仅有任意表格标题不足以生成大纲。第五列是教学价值，不是定位。定位在第六列写章节/行号，章节标题也必须保留。

```markdown
# 组件清单
**2 个组件**
## 三、逐章组件明细
### 第一章（来源）
| ID | 组件名 | 类型 | 整理者概括 | 教学价值 | 定位 |
|---|---|---|---|---|---|
| C001 | 任务识别 | tool | 根据任务特征选择操作路径 | 避免误操作 | 第一章 L1-L20 |
| C002 | 复核清单 | tool | 完成后逐项复核结果 | 形成操作闭环 | 第一章 L21-L40 |
```

编排方案使用 `## 二、模块序列`，列顺序为 `# / 模块名 / 层级 / 分钟 / Do意图 / 组件 ID / 主教学处理`。模块编号用 `M0`、`M1` 等，分钟为正整数；Do 意图填写 P/E/T/R，非 Do 用 —。未选用表置于 `## 四、未选用组件清单`，列顺序为 `ID / 名称 / 类型 / 去向 / 理由`，去向为舍/自学/备选/带出。两表须覆盖全部组件且不重复；总时长写在正文。

大纲头部用反引号登记唯一上游，推荐项目根目录相对路径：

```text
**上游**：`plans/编排方案A.md` / `组件清单.md`
```

生成器会创建缺失的输出父目录，并自动保留相对于大纲所在目录的上游路径；总控同时支持大纲相对路径和项目根相对路径。引用必须仍在项目内，不能只留下有歧义的同名文件。

模块详情采用生成器格式，不自行改成另一种表述后期待校验器猜测：

```markdown
### M0 · 方法练习（Do，30 分钟）
**建议时长**：30 分钟
| 组件 | 核心内容 |
|---|---|
| C001 | 任务识别与操作 |
```

模块名称、顺序、层级、时长、组件逐模块归属须与编排方案一致。全局组件集合相同不代表归属相同。保持生成器的 13 个一级小节，补完所有 `【AI 补：…】`，再执行 `verify --strict`。

## 课表与时间口径

分钟级表的第一列是 `HH:MM-HH:MM`，其他列遵循 FIRE 的十列教学设计要求。教学单元栏标 `M0` 等模块号，或者提供能唯一对应模块的 `C001` 组件号。仅休息、茶歇、午休、签到、过渡可以不分配模块。

```markdown
总时长 70 分钟。
## Day 1
| 时间 | 教学单元 | 组件 |
|---|---|---|
| 09:00-09:30 | M0 方法练习 | C001 |
| 09:30-09:40 | 茶歇 | — |
| 09:40-10:10 | M1 迁移练习 | C002 |
```

上表仅展示解析字段，不代替完整十列教学设计。换天必须显式写 `## Day 2`、`## 第二天` 或日期标题；同一天内不得重叠或漏排时间，午休也须有行。跨午夜请拆成两个日期，不能以结束时间倒退暗示。

- GROSS 总包：课表全部区间之和，包含休息；需求说明书、大纲、计划必须明写 `总时长 N 分钟`（计划也支持总课时/总包时长）。
- NET 净教学：大纲模块时长之和，与课表逐模块实排相等；可写 `教学时长 N 分钟`。
- PERDAY：各个明确日期分别实算；不能用平均每天掩盖长短不一。非均匀日程避免笼统写“每天 N 分钟”，分别写 Day 1 / Day 2 的分钟数。
- 短课如 90 分钟也检查，不以三位数为门槛。
- 成对引号内的旧方案时长仅视为引用；正式声明必须在引号外，引用不能替代声明。

## 可移植回归

在 scripts 目录执行，使用有 PyYAML 的 Python（本机为知识库构建器独立环境）：

```text
python -m unittest discover -s . -p test_regressions.py -v
python selftest_plan_to_outline.py
python selftest_check_consistency.py
```

用例自行生成合成资料并使用临时目录，不依赖作者电脑、真实课程或外部盘符。自动通过只表示相应检查契约成立，不是对教学质量的验收。
